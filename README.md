# Простой графический редактор для создания мемов

Вариант 72. Материалы лабораторных работ № 1–3.

Браузерное приложение для создания мема из изображения и текстовых блоков. Редактор работает в браузере без загрузки исходных данных на сервер.

## Лабораторная работа № 3 — запуск редактора

В каталоге проекта выполните `python3 -m http.server 8000` и откройте `http://localhost:8000`. Выберите «Загрузить изображение» или начните с пустого холста, добавьте надписи и нажмите «Скачать мем». Поддерживаются PNG, JPEG и WebP до 10 000 000 байт. Пустой холст имеет размер 1200 × 1200; изображение экспортируется в исходном разрешении.

Текстовые блоки редактируются по отдельности; доступны обводка, выравнивание, перемещение мышью и стрелками, порядок слоёв, отмена и повтор. Изображение и текст обрабатываются локально в браузере.

Для автоматической проверки нужны Node.js 20+ и Chrome/Chromium: `npm ci && npm test`. При нестандартном расположении браузера задайте `CHROME_PATH`. Тесты проверяют модель сцены, 20 отмен и повторов, загрузку и ошибки файлов, размер PNG, несколько надписей, ширину 320 пикселей и отсутствие сторонних сетевых запросов.

Это учебный прототип. Проверка полного списка браузеров и устройств из ТЗ, а также устойчивости на устройстве с 2 ГБ ОЗУ ещё не проводилась.
