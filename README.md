# Простой графический редактор для создания мемов

Материалы лабораторной работы № 1 «Разработка и управление требованиями к программному обеспечению». Вариант 72.

Цель приложения — дать пользователю простой браузерный редактор для создания мема из изображения, текста и базовых элементов оформления. В этой работе описаны требования к приложению; программная реализация в состав лабораторной работы не входит.
