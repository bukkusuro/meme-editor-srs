### User Story

Как пользователь, я хочу видеть результат и скачать его в PNG, чтобы отправить готовый мем.

### Критерии приёмки

- [ ] Предварительный просмотр обновляется после каждого изменения без перезагрузки страницы.
- [ ] Кнопка «Скачать мем» доступна после создания проекта.
- [ ] Файл скачивается в формате PNG под именем `meme.png`.
- [ ] Разрешение файла не меньше разрешения исходного изображения.
- [ ] Скачанный файл визуально совпадает с предварительным просмотром.

**Связано с ТЗ:** [раздел 2.4, FR-08–FR-10](https://github.com/bukkusuro/meme-editor-srs/wiki/Техническое-задание).
