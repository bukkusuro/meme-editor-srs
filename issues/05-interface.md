### User Story

Как пользователь, я хочу понятный редактор на компьютере и телефоне, чтобы создавать мем без обучения.

### Критерии приёмки

- [ ] Подписи и сообщения интерфейса отображаются на русском языке.
- [ ] Главные инструменты видимы без открытия меню.
- [ ] При ширине окна 320 пикселей нет горизонтальной прокрутки.
- [ ] Основные действия доступны с клавиатуры, а выбранный объект имеет видимый маркер.
- [ ] Приложение запускается без установки и регистрации в поддерживаемых браузерах.
